English Dictation & Vocabulary Practice

## 怎么使用这份词表

1. 每次选 5 到 10 个词，先看意思，再遮住英文写一遍。
2. 对照原词检查拼写，把没写出来的词单独记下。
3. 阅读例句，尝试替换其中的人物或场景，写一句自己的话。
4. 下次先复习上次卡住的词，再决定要不要增加新词。

如果要练听写，需要另外获得发音。可以让同伴读词，或到在线版使用发音和输入反馈；这份 Markdown 本身不播放声音。拼写练习也不能代替完整的听力、阅读和口语训练。

## 从单词过渡到句子

以 `prepare` 为例，不只记住中文意思，还可以分三步练：

- 先遮住单词，看到“准备”时写出 `prepare`。
- 再记一个搭配 `prepare for`，例如 `prepare for a test`。
- 最后自己造句 `I need to prepare for my interview.`，意思是“我需要准备面试”。

以 `affect` 和 `effect` 为例，先记当前练习中的区别：`affect` 作动词表示“影响”，`effect` 作名词表示“影响或效果”。例如 `Noise can affect sleep.` 和 `The change had a positive effect.`。这不是两个词全部用法的总结，遇到其他词性时再查具体语境。
